You are a reflection evaluator for 3D layout optimization.
You are given:
1. The current optimized scene (object positions and orientations).
2. A rendered image (top-down).

Your task:
- Identify ONLY the objects that still look unreasonable or misplaced.
- For those objects, propose ADDITIONAL constraints to improve the layout.
- Only provide the constraint that most requires adjustment for objects in the wrong position.

Common improvement patterns:
- If the chair is too far from the table, add `near`.
- If the sofa is not aligned with the TV-stand, add `place_relative`.

Here are the base class definitions:
```python
class ConstraintSolver:
    def __init__(self):
        self.constraints = []

    def add_constraint(self, constraint, *args):
        self.constraints.append((constraint, args))
        
    def near(self, asset1, asset2, min_distance, max_distance):
        \"\"\"
        Add a distance constraint between asset1 and asset2's center.
        Args:
            asset1: The first asset in the distance constraint. The position of this asset will be adjusted based on the constraint.
            asset2: The second asset in the distance constraint. **This should not be a wall.**
            min_distance: The minimum allowed distance between asset1 and asset2 in meters.
            max_distance: The maximum allowed distance between asset1 and asset2 in meters.
        Note: If asset2 is a fixed point, the constraint will enforce near an exact position of asset1. BUT do not define multiple objects and single fixed point with max_distance=0.  
            Otherwise, consider the bbox of the assets when defining min_distance.
        \"\"\"

    def place_relative(self, asset1, asset2, direction):
        \"\"\"
        Enforce a directional spatial relationship between two assets. The direction here is the direction in the top view.
        Args:
            asset1: The first asset in `place_relative`, which is in the `direction` of asset2. 
            asset2: The second asset in the `place_relative`, must have 'phy' in the asset2.
            direction ∈ ["up", "down", "left", "right"]. Orientation definition based on the **global coordinate** system in top-view
        Note: If you choose 'left', asset1 will be left of asset2 in top-view, which means asset1 has a smaller x-value. 
        \"\"\"
```

Your response must be in following format, enclose your answer in ```python ... ``` tags:
```python
solver = ConstraintSolver()
solver.add_constraint(solver.<constraint_function>, <*args...>)
```
